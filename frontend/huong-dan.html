Tải và cài đặt Download & Install

  1. Bấm nút Tải về ở góc trên trang để tải tệp Fall_and_Stroke_Warning_System_Setup.exe. Click the Download button in the top navigation to download Fall_and_Stroke_Warning_System_Setup.exe.
  2. Mở thư mục Downloads và nhấp đúp vào tệp vừa tải. Open your Downloads folder and double-click the installer file.
  3. Nếu Windows hiện màn hình xanh “Windows protected your PC”: bấm More info (Thông tin thêm) rồi bấm Run anyway (Vẫn chạy). If Windows displays "Windows protected your PC": click More info then click Run anyway.
  4. Chọn ngôn ngữ cho trình cài đặt (Tiếng Việt hoặc English). Choose your installer language (Tiếng Việt or English).
  5. Ở bước chọn tác vụ bổ sung: In the additional tasks step:
    • Tích Tạo biểu tượng trên Màn hình chính (Desktop) để mở ứng dụng nhanh. Check Create a desktop shortcut for quick access.
    • Tích Tự động chạy bảo vệ khi khởi động Windows nếu máy này dùng để giám sát 24/7 (có thể bật/tắt lại sau trong phần Cài đặt). Check Autostart protection when Windows boots for continuous 24/7 surveillance (can also be toggled in Settings later).
  6. Bấm Install và chờ khoảng 1 phút. Click Install and wait about 1 minute.
  7. Ở màn hình cuối, giữ dấu tích Mở Fall and Stroke Warning System ngay rồi bấm Finish. On the final screen, keep Launch Fall and Stroke Warning System checked and click Finish.
ℹ️
Phần mềm cài vào %LOCALAPPDATA%\Programs\Fall_and_Stroke_Warning_System, không cần quyền quản trị. Bạn không cần cài Python hay bất kỳ phần mềm nào khác. The software installs to %LOCALAPPDATA%\Programs\Fall_and_Stroke_Warning_System without requiring administrative rights. You do not need to install Python or any extra dependencies.
Vì sao Windows hiện cảnh báo khi cài? Why does Windows show a security warning during install?

Phần mềm mã nguồn mở này chưa có chữ ký số doanh nghiệp, nên Windows SmartScreen cảnh báo với mọi tệp tải từ Internet chưa đủ “uy tín”. Đây không phải dấu hiệu virus. Nếu máy dùng Smart App Control (Windows 11 cài mới) và không có nút Run anyway, xem mục Xử lý sự cố. This open-source software is independently built without expensive enterprise code-signing certificates, so Windows SmartScreen displays a precautionary note for newly downloaded files. This is not a virus. If your system runs Smart App Control (clean Windows 11 installs) and lacks a Run anyway button, see the Troubleshooting section.

Khởi động lần đầu First Launch

  1. Nhấp đúp biểu tượng Fall and Stroke Warning System trên Desktop (hoặc tìm trong menu Start). Double-click the Fall and Stroke Warning System shortcut on Desktop (or launch from Start menu).
  2. Chờ 10–30 giây để hệ thống nạp mô hình AI. Ứng dụng chạy ngầm nên không có cửa sổ đen hiện ra, đây là bình thường. Wait 10–30 seconds for AI models to initialize in memory. The process runs quietly in the background with no command prompt popups.
  3. Cửa sổ giao diện tự mở. Nếu sau 1 phút vẫn không thấy, mở trình duyệt và vào http://localhost:8000. The dashboard window opens automatically. If not shown after 1 minute, open any browser and visit http://localhost:8000.
  4. Nếu Windows hỏi cho phép truy cập mạng (Windows Defender Firewall): bấm Allow. Cần bước này nếu muốn xem từ điện thoại hoặc máy khác. If Windows prompts for network access permissions (Windows Defender Firewall): click Allow. This enables viewing from phones or other local devices.
  5. Nếu Windows hỏi quyền dùng camera: bấm Yes / Cho phép. If Windows asks for camera access permission: click Yes / Allow.
✅
Ứng dụng tự bật Webcam 0 (webcam mặc định của máy). Nếu thấy hình ảnh trực tiếp trong khung CAMERA 01 là hệ thống đã sẵn sàng. The app automatically starts Webcam 0 (default camera). When live video is displayed in the CAMERA 01 feed, the system is fully operational.

Kết nối webcam (tích hợp hoặc USB) Connecting Webcams (Built-in or USB)

  1. Cắm webcam USB vào máy (bỏ qua nếu dùng webcam của laptop). Plug your USB webcam into the computer (skip if using laptop built-in webcam).
  2. Trên khung camera, bấm •••, tìm phần CẤU HÌNH NGUỒN CAMERA. On the camera feed card, click ••• and locate CAMERA SOURCE CONFIG.
  3. Ở Loại Nguồn, chọn 📷 Webcam Tích hợp / USB. Under Source Type, select 📷 Integrated / USB Webcam.
  4. Bấm Quét để tìm các webcam đang cắm, rồi chọn webcam trong ô Chọn Webcam. Webcam 0 thường là webcam laptop, webcam USB thường là Webcam 1. Click Scan to detect connected devices, then select your webcam in the Select Webcam dropdown (Webcam 0 is usually internal, Webcam 1 is external USB).
  5. Bấm ÁP DỤNG CAMERA và chờ vài giây để hình hiện lên. Click APPLY CAMERA and wait a few seconds for video feed to stream.
  6. Bấm LƯU MẶC ĐỊNH để lần sau mở ứng dụng sẽ tự dùng camera này. Click SAVE AS DEFAULT so the system automatically uses this camera on subsequent launches.

Kết nối camera IP an ninh (RTSP) Connecting IP Security Cameras (RTSP)

Camera IP gắn tường, gắn trần cho góc nhìn bao quát hơn webcam. Máy tính và camera phải cùng mạng Wi-Fi / mạng nội bộ. Wall- or ceiling-mounted IP cameras provide a much wider angle than a laptop webcam. The computer and camera must be on the same Wi-Fi / local network.

Bước A — Lấy thông tin camera Step A — Gather Camera Credentials

  • Địa chỉ IP của camera: xem trong ứng dụng điện thoại của hãng (mục thông tin thiết bị) hoặc trong trang quản trị modem/router (danh sách thiết bị đã kết nối). Ví dụ: 192.168.1.100. Camera IP Address: check in the manufacturer mobile app (device info section) or in your router admin portal (connected clients list), e.g. 192.168.1.100.
  • Tên đăng nhập và mật khẩu của camera (không phải mật khẩu tài khoản app). Camera hardware username and password (not your cloud mobile app account password).
  • Đảm bảo RTSP / ONVIF đã được bật trong cài đặt camera. Ensure RTSP / ONVIF protocol is enabled in the camera device settings.

Bước B — Nhập vào ứng dụng Step B — Configure in the Application

  1. Bấm ••• trên khung camera. Click ••• on the camera feed card.
  2. Loại Nguồn: chọn 🌐 Camera IP / Camera ở xa (RTSP, HTTP, RTMP). Source Type: select 🌐 IP Camera / Remote Camera (RTSP, HTTP, RTMP).
  3. Hãng Camera: chọn đúng hãng. Ô Đường dẫn camera sẽ tự điền mẫu. Camera Brand: select your camera maker. The URL field will autofill an RTSP template.
  4. Sửa đường dẫn: thay tên đăng nhập, mật khẩu và địa chỉ IP bằng thông tin thật của camera. Customize the path: substitute with your camera's real username, password, and local IP.
  5. Bấm ÁP DỤNG CAMERA. Có hình là kết nối thành công, sau đó bấm LƯU MẶC ĐỊNH. Click APPLY CAMERA. Once video appears, click SAVE AS DEFAULT.

Đặt camera đúng cách để AI nhận diện chính xác Optimal Camera Placement for Accurate AI Detection

📐 Độ cao 2–2,5 m, chếch xuống 📐 Height 2–2.5 m, tilted downward

Nhìn bao quát cả sàn nhà, vì người ngã sẽ nằm trên sàn. Provides wide coverage of the floor where fallen individuals land.

🧍 Thấy được toàn thân 🧍 Full-body visibility

Khung hình nên chứa trọn người từ đầu đến chân ở khu vực hay đi lại. Frame should capture the person from head to toe in common walking areas.

💡 Đủ sáng, không ngược sáng 💡 Adequate lighting, avoid backlight

Tránh hướng camera thẳng vào cửa sổ. Ban đêm dùng camera có hồng ngoại hoặc để đèn ngủ. Avoid pointing camera into bright windows. At night, use infrared night vision or soft night lights.

🚧 Ít vật che khuất 🚧 Minimal occlusions

Hạn chế bàn ghế, lan can che phần thân dưới. Mỗi phòng cần giám sát nên có một camera riêng. Keep lower body visible without tables or railings blocking legs. Use dedicated cameras per room.

Ưu tiên các khu vực dễ xảy ra ngã: phòng ngủ, lối đi tới nhà vệ sinh, phòng khách, cầu thang. Prioritize areas with high fall probability: bedrooms, pathways to bathrooms, living rooms, and stairs.

Theo dõi giám sát Live Monitoring & Risk States

Khi đang chạy, mỗi người trong khung hình được vẽ khung xương và một thẻ trạng thái. Màu cho biết mức nguy cơ: During monitoring, each person in view receives an overlaid 17-keypoint skeleton and a status badge. Colors indicate real-time risk level:

MàuColor Trạng tháiRisk State Ý nghĩaMeaning
Xanh láGreen NORMAL Sinh hoạt bình thường: đi, đứng, ngồi, cúi nhặt đồNormal daily activities: walking, standing, sitting, bending to retrieve items
VàngYellow SUSPICIOUS Có dấu hiệu cần chú ý (loạng choạng, tư thế lạ)Suspicious behavior: temporary stumbling or unusual posture
CamOrange ABNORMAL Nghi ngã hoặc biểu hiện bất thường kéo dàiAbnormal state: prolonged irregular pose or suspected fall impact
ĐỏRed HIGH RISK / ALERT Nguy cơ cao, hệ thống phát cảnh báo; khung video có viền đỏHigh emergency risk: audio alarm triggers, red flashing screen border

Hệ thống theo dõi các dấu hiệu nhìn thấy được qua camera: ngã đột ngột, nằm bất động trên sàn, loạng choạng mất thăng bằng, ôm đầu, ôm ngực, nôn ói. The AI observes visible kinematics via camera: sudden impact drops, prolonged immobility on the floor, severe stumbling/loss of balance, clutching head/chest, and convulsions.

Các nút điều khiển Player Controls

  • ⏯ Tạm dừng / Tiếp tục luồng video. ⏯ Pause / Resume live video stream.
  • 🔊 Bật / Tắt âm thanh chuông cảnh báo trên máy tính. 🔊 Mute / Unmute emergency audio chime on this computer.
  • 📷 Chụp ảnh nhanh màn hình hiện tại. 📷 Snapshot current camera frame.
  • ⛶ Phóng to toàn màn hình. ⛶ Fullscreen view for wall or secondary monitors.
🔊
Nên để bật âm thanh và loa máy tính ở mức nghe rõ, để người trong nhà nghe được chuông khi có cảnh báo. Keep audio unmuted with computer speakers turned up so family members hear the alert chime instantly.

Khi có cảnh báo When an Emergency Alert Fires

  1. Thanh đỏ “PHÁT HIỆN HÀNH VI BẤT THƯỜNG / NGUY CƠ TÉ NGÃ!” hiện trên đầu màn hình kèm chuông báo. Nếu đã cài Telegram, điện thoại cũng nhận tin nhắn kèm ảnh. A red flash bar "ABNORMAL BEHAVIOR / FALL RISK DETECTED!" appears at the top accompanied by an alarm chime. If Telegram is set up, your phone receives an immediate notification with photo snapshot.
  2. Kiểm tra người thân ngay lập tức: đến tận nơi hoặc gọi điện. Check the person immediately: approach in person or make a direct voice/video call.
  3. Sau khi đã kiểm tra, bấm ĐÃ XÁC NHẬN (DISMISS) để tắt cảnh báo. After checking the situation, click CONFIRMED (DISMISS) to silence the active alert banner.
  4. Ở thẻ CẢNH BÁO TÉ NGÃ: bấm Xử lý để đánh dấu sự việc đã giải quyết, hoặc Xem chi tiết để xem trong lịch sử cảnh báo. On the FALL ALERT card: click Process / Resolve to mark it resolved, or View Details to inspect the event history log.
🚑
Phần mềm chỉ hỗ trợ cảnh báo, không chẩn đoán bệnh. Tin nhắn luôn là: “Possible medical emergency / abnormal behavior detected. Please check the person.” (Có thể có tình huống khẩn cấp, hãy kiểm tra người thân). Nếu nghi ngờ đột quỵ (méo miệng, yếu nửa người, nói khó) hoặc chấn thương nặng, gọi cấp cứu 115 ngay. This system is a safety decision-support tool, not a medical diagnosis device. The alert notification strictly states: "Possible medical emergency / abnormal behavior detected. Please check the person." If a stroke (facial droop, arm weakness, speech difficulty) or severe injury is suspected, call emergency medical services immediately (115 / 911).

Ảnh chụp lúc xảy ra sự việc được lưu trên máy tại thư mục cài đặt, mục data\processed\events. Incident snapshots are archived locally in your project folder under data\processed\events.

Nhận cảnh báo qua Telegram trên điện thoại Receiving Phone Alerts via Telegram

Để nhận tin ngay cả khi không ở gần máy tính, cài ứng dụng Telegram trên điện thoại, sau đó: To receive instant notifications even when away from your PC, install Telegram on your phone, then:

  1. Mở Telegram, tìm @BotFather, gửi lệnh /newbot và đặt tên cho bot (ví dụ: Canh bao nha ba). Open Telegram, search for @BotFather, send the /newbot command, and choose a name and username for your alert bot.
  2. BotFather gửi về một Bot Token dạng 123456789:AAH.... Sao chép đoạn này. BotFather will reply with a Bot Token (e.g. 123456789:AAH...). Copy this token string.
  3. Trên ứng dụng giám sát, mở ⚙️ Cài đặt → mục 📱 Thông báo qua Telegram, dán vào ô Bot Token. In the monitoring dashboard, open ⚙️ Settings → scroll to 📱 Telegram Notifications, and paste it into the Bot Token field.
  4. Trên Telegram, mở bot vừa tạo và bấm Start. Muốn cả nhà cùng nhận: thêm bot vào nhóm gia đình rồi nhắn một tin bất kỳ trong nhóm. In Telegram, open your newly created bot and click Start. For multi-person alerts: add the bot to a family group chat and send any message.
  5. Quay lại ứng dụng, bấm 🔎 Lấy Chat ID tự động. Ô Chat ID sẽ tự điền. Return to the app and click 🔎 Auto-detect Chat ID. The Chat ID field will automatically populate.
  6. Bật công tắc Telegram, bấm 💾 Lưu cài đặt. Switch the Telegram toggle ON, then click 💾 Save Settings.
  7. Bấm 📨 Gửi tin thử. Điện thoại nhận được tin là đã cài xong. Click 📨 Send Test Message. Once your phone receives the test ping with photo, setup is complete!
🌐
Gửi Telegram cần máy tính có Internet. Mọi phân tích hình ảnh vẫn diễn ra trên máy, hệ thống chỉ gửi tin cảnh báo tới bot của bạn. Telegram dispatch requires an active internet connection on the host PC. All video analysis occurs strictly offline; only alert text and snapshot photos are transmitted to your private bot.

Tự chạy cùng Windows (giám sát 24/7) Autostart with Windows (24/7 Surveillance)

  1. Mở ⚙️ Cài đặt. Open ⚙️ Settings.
  2. Gạt công tắc 🚀 Tự động chạy nền khi mở máy tính sang bật. Switch the toggle 🚀 Automatically run in background on startup to ON.
  3. Từ lần khởi động máy sau, hệ thống tự chạy ngầm với camera đã LƯU MẶC ĐỊNH, không cần mở tay. On every subsequent computer boot, the system automatically launches in background using your saved DEFAULT CAMERA without manual interaction.

Gạt công tắc về tắt nếu không muốn tự chạy nữa. Switch the toggle OFF whenever you wish to disable autostart.

  1. Trên máy đang chạy hệ thống, mở Command Prompt (gõ cmd trong menu Start), gõ ipconfig và nhấn Enter. Ghi lại dòng IPv4 Address, ví dụ 192.168.1.25. On the host PC, open Command Prompt (type cmd in Start menu), type ipconfig, and press Enter. Note the IPv4 Address (e.g. 192.168.1.25).
  2. Trên điện thoại hoặc máy khác cùng mạng Wi-Fi, mở trình duyệt và vào http://192.168.1.25:8000 (thay bằng IP vừa ghi). On your smartphone or secondary device connected to the same Wi-Fi network, open the browser and navigate to http://192.168.1.25:8000 (substitute with your host IP).

Nếu không vào được: kiểm tra đã bấm Allow ở hộp thoại Windows Firewall lần đầu chạy; nếu lỡ bấm Cancel, vào Windows Security → Firewall & network protection → Allow an app through firewall và cho phép ứng dụng. Quyền riêng tư & Bảo mật dữ liệu Privacy & Data Security

  • Hình ảnh camera được xử lý hoàn toàn trên máy tính của bạn, không gửi lên máy chủ nào. All camera video frames are processed entirely on your local PC; no video streams are sent to external cloud servers.
  • Muốn che mặt người trong khung hình: ⚙️ Cài đặt → bật 🔒 Bảo vệ quyền riêng tư (Làm mờ mặt). To conceal identities: open ⚙️ Settings → toggle on 🔒 Privacy Protection (Face Blur).
  • Ảnh sự cố chỉ lưu trên máy, trong thư mục data\processed\events của thư mục cài đặt. Bạn có thể xóa thủ công khi không cần nữa. Incident snapshots are kept strictly on your local disk in data\processed\events. You can inspect or delete them at any time.
  • Dữ liệu chỉ rời máy khi bạn bật Telegram, và chỉ gửi tới bot do bạn tạo. Data only leaves your machine if you enable Telegram notifications, sending encrypted alerts directly to your private bot.
  • Mật khẩu camera IP và Bot Token Telegram được lưu riêng cho tài khoản Windows của bạn trong %APPDATA%\FallStrokeWarning, không nằm trong thư mục cài đặt. IP camera credentials and Telegram tokens are securely kept in your user profile at %APPDATA%\FallStrokeWarning.

Xử lý sự cố Troubleshooting & FAQs

Không cài được: Smart App Control chặn, không có nút “Run anyway” Cannot install: Smart App Control blocks installer without "Run anyway" button

Trên Windows 11 cài mới, Smart App Control chặn mọi ứng dụng chưa ký số. Thử chuột phải tệp cài → Properties → tích Unblock → OK rồi chạy lại. Nếu vẫn bị chặn, chỉ còn cách tắt Smart App Control trong Windows Security → App & browser control. Lưu ý: đã tắt thì không bật lại được nếu không cài lại Windows. On clean Windows 11 installs, Smart App Control blocks unsigned executable files. Try right-clicking the setup file → Properties → check Unblock → click OK and run again. If still blocked, Smart App Control can be disabled in Windows Security → App & browser control (note: Microsoft does not permit re-enabling it without reinstalling Windows).

Khung camera đen hoặc báo “camera bận” Camera preview is black or shows "Camera busy"
  • Đóng các ứng dụng khác đang dùng camera (Zoom, Teams, Zalo, Camera…). Close other applications currently accessing the camera (Zoom, Teams, Skype, Windows Camera).
  • Vào ⚙️ Cài đặt → 🔍 Kiểm tra Camera để chẩn đoán. Navigate to ⚙️ Settings → click 🔍 Check Camera to diagnose availability.
  • Bấm 🔓 Mở Cài đặt Quyền Camera Windows, bật Camera access và Let desktop apps access your camera. Click 🔓 Open Windows Camera Privacy Settings, enable Camera access and Let desktop apps access your camera.
  • Thử chọn webcam khác bằng nút Quét (Webcam 0 / 1). Try selecting another connected webcam using the Scan button (Webcam 0 / 1).
  • Rút ra cắm lại webcam USB sang cổng USB khác trên máy. Unplug and reconnect the USB webcam into a different USB port.
Camera IP không kết nối được IP Camera cannot connect
  • Kiểm tra máy tính và camera cùng mạng; thử ping 192.168.1.100 trong Command Prompt. Verify PC and camera are on the same subnet; test with ping 192.168.1.100 in Command Prompt.
  • Kiểm tra lại tên đăng nhập, mật khẩu (EZVIZ dùng mã xác minh trên tem, Tapo dùng “Tài khoản camera”). Re-check username/password (EZVIZ uses printed verification code; Tapo requires a Camera Account created in Tapo app).
  • Đảm bảo RTSP/ONVIF đã bật trong app của hãng. Ensure RTSP/ONVIF streaming is enabled in the camera mobile app.
  • Kiểm tra đường dẫn bằng phần mềm VLC: Media → Open Network Stream, dán đường dẫn RTSP. VLC xem được thì ứng dụng cũng kết nối được. Test the RTSP URL in VLC media player: Media → Open Network Stream. If VLC displays video, the app will connect seamlessly.
  • Camera đổi IP sau khi khởi động lại modem: đặt IP tĩnh (DHCP Reservation) cho camera trong modem. If the camera IP changed after router reboot: assign a static DHCP reservation to the camera in your router.
Video giật, FPS thấp Video stutter or low FPS
  • Cắm sạc laptop; chọn chế độ nguồn Best performance. Plug in your laptop charger and select Best performance power profile.
  • Với camera IP, dùng luồng phụ (Hikvision 102, Dahua subtype=1, Tapo stream2). For IP cameras, switch to the sub-stream (Hikvision 102, Dahua subtype=1, Tapo stream2).
  • Đóng bớt các chương trình đồ họa nặng đang chạy. Close background programs with high GPU/CPU utilization.
  • Xem số FPS hiện tại ở mục 📊 Thống kê; khoảng 15 FPS trở lên là đủ để nhận diện tốt. Observe the FPS counter in 📊 Statistics; 15+ FPS is sufficient for reliable real-time AI tracking.
Giao diện không mở / trang localhost:8000 không vào được UI window fails to appear or localhost:8000 unreachable
  • Chờ thêm 30 giây sau khi mở ứng dụng rồi tải lại trang. Wait 30 seconds after launching the app for model loading, then refresh the browser tab.
  • Có thể ứng dụng đã chạy ngầm từ trước: chỉ cần vào http://localhost:8000, không mở thêm lần nữa. The process might already be running in the background: simply visit http://localhost:8000 without opening another instance.
  • Cổng 8000 bị chương trình khác chiếm: tắt chương trình đó, hoặc khởi động lại máy rồi mở lại ứng dụng. Port 8000 might be claimed by another application: close conflicting servers or reboot the PC and re-launch.
Không nhận được tin Telegram Telegram notifications not arriving
  • Kiểm tra máy tính có kết nối Internet. Check that the PC has an active internet connection.
  • Đã bấm Start với bot (hoặc đã nhắn một tin trong nhóm có bot) trước khi bấm Lấy Chat ID tự động. Ensure you clicked Start in the bot chat (or sent a message in the group containing the bot) prior to auto-detecting Chat ID.
  • Bấm 📨 Gửi tin thử và đọc thông báo lỗi hiện ra. Click 📨 Send Test Message and inspect the diagnostic feedback message.
Cảnh báo nhầm hoặc bỏ sót False alerts or missed occurrences
  • Kiểm tra lại vị trí camera theo mục 7: thấy toàn thân, đủ sáng, ít bị che. Verify camera placement according to Section 7: head-to-toe visibility, proper lighting, minimal obstructions.
  • Người ra khỏi khung hình hoặc bị che khuất hoàn toàn thì hệ thống không thể theo dõi. If an individual leaves camera view or is occluded by tall furniture, the system cannot maintain pose tracking.
  • Hệ thống chỉ là công cụ hỗ trợ an toàn, không thay thế sự chăm sóc trực tiếp của người thân. This solution is a decision-support and safety aid; it does not replace direct caregiving.
Gửi thông tin lỗi cho nhà phát triển Sending diagnostic logs to developers

Nhật ký hoạt động nằm ở %LOCALAPPDATA%\Programs\Fall_and_Stroke_Warning_System\app_log.txt (dán đường dẫn này vào thanh địa chỉ của File Explorer). Gửi kèm tệp này khi báo lỗi trên GitHub. Operational logs are located at %LOCALAPPDATA%\Programs\Fall_and_Stroke_Warning_System\app_log.txt (paste into File Explorer address bar). Attach this file when filing a bug report on GitHub.

Gỡ cài đặt Uninstallation

  1. Tắt hệ thống bằng nút TẮT HỆ THỐNG trong Cài đặt. Shut down the background system using SHUTDOWN SYSTEM in Settings.
  2. Mở Settings → Apps → Installed apps, tìm Fall and Stroke Warning System → Uninstall. Hoặc dùng lối tắt gỡ cài đặt trong menu Start. Open Windows Settings → Apps → Installed apps, find Fall and Stroke Warning System → click Uninstall, or launch the uninstaller shortcut from Start Menu.
  3. Trình gỡ cài đặt cũng xóa mục tự chạy cùng Windows. The uninstaller cleanly deletes startup registry hooks and installed binaries.
